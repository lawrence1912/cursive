# cursive 品牌资产

**主旨：随心所欲，所见即所得。**

## 名字

*cursive* 字面是「草书」——随手连笔写下去，正是"随心所欲"。
而它和 *cursor*（光标）同一个拉丁词根 **currere**（跑）：书写的手在纸上跑，光标在行里跑，
本来就是同一件事。产品那两句话，一个词说完了。

念 /ˈkɜːrsɪv/，两音节。全小写书写，不首字母大写。

## 标志怎么读

标志是一个**开口朝右的 C** —— cursive 的首字母，也是一笔画到底的一条线。

- **缺口就是光标停的地方。** 写到哪儿，C 就断在哪儿；蓝色那根光标正停在缺口上。
  它是整个标志里唯一的彩色、唯一发光的东西 —— 名字里的那个 cursor，就是它。
- **大尺寸的标志，在 C 的怀里多一行。** 灰色方块是 markdown 标记，因为**光标正停在这一行**
  才显形；后面那节墨色胶囊，是排好版的成品。标记与成品共用同一段文字，是光标决定你此刻
  看见哪一面——这既是"所见即所得"，也正是 cursive 的核心机制：
  *光标移进哪一行，哪一行才回显源码。*
- **应用图标是标志的简化版：只留 C 和光标。** 图标真正的工作场合是 16–64px（Dock、
  Finder 列表、⌘Tab），那个尺寸上只有「一个 C，缺口上停着光标」立得住；怀里那一行
  32px 起就糊成一团。所以怀里那一行交给 `logo-mark`，从 128px 起才出场。

形体上，C 是圆头的一整笔，胶囊块有厚度、有落影、有受光的顶面；底是一块温润的纸色瓷砖。

标志里没有"草书"的笔迹，这是故意的：字标和图标都是规整的几何单线，*cursive* 的意思
由名字本身承担，不必让图形再演一遍——真让图形去写草书，只会和圆头胶囊块打架。

## 文件

| 文件 | 用途 |
|---|---|
| `app-icon.svg` | macOS 应用图标 1024，**主版本**（C + 光标，纸色瓷砖） |
| `app-icon-dark.svg` | 应用图标，深色瓷砖变体 |
| `logo-mark.svg` | 标志（C + 怀里那一行），无瓷砖底，浅背景用；**128px 以上才用** |
| `logo-mark-dark.svg` | 标志，无瓷砖底，深背景用 |
| `logo-mark-mono.svg` | 单色，跟随 `currentColor`（印刷、刻印） |
| `logo-lockup.svg` / `-dark` | 应用图标 + 字标横排组合 |
| `wordmark.svg` / `-dark` | 字标单独用 |
| `favicon.svg` | 16–32px 专用简化版（C + 光标，笔画按像素加粗） |

字标是纯路径的圆头几何单线体，x 高 56、笔画 13、圆头收笔，与图标的胶囊块同一套语言；不依赖任何字体文件。

光标蓝与 app 的 `--accent`（`#0969da` / `#6ba6e8`）同族：标志上发光的这一根，
在产品里就是选中、链接和光标的颜色。

## 用法

- **留白**：四周留出不少于图标边长 7% 的空白。
- **最小尺寸**：应用图标 16px（.icns 每一档都从矢量重新栅格，16px 上 C 仍然读得出来）；
  `logo-mark` 128px（怀里那一行再小就糊 —— 那个尺寸是应用图标的活）；组合标志 140px。
  再小请用 `favicon.svg`。
- **别做**：别把光标挪出缺口（**缺口 = 光标位**，挪开语义就没了）、别把 `logo-mark`
  用在 128px 以下、别拉伸、别给图标再加外阴影或描边。

## 重新生成应用图标

矢量源**只有 `brand/app-icon.svg` 一份**。`sips` 直接吃 SVG（渐变、柔和投影、透明都保真），
所以不再需要「浏览器打开导出页截图」那一步 —— 旧的 `scripts/icon.html` 已删，它注定与
SVG 对不上。

```
npm run icon      # brand/app-icon.svg → build/icon.png（1024 母版）+ build/icon.icns
```

`.icns` 里每一档尺寸都是**从矢量重新栅格**的（不是把 1024 缩下去），16/32px 才不糊。
