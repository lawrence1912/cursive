# cursive 品牌资产

**主旨：随心所欲，所见即所得。**

## 名字

*cursive* 字面是「草书」——随手连笔写下去，正是"随心所欲"。
而它和 *cursor*（光标）同一个拉丁词根 **currere**（跑）：书写的手在纸上跑，光标在行里跑，
本来就是同一件事。产品那两句话，一个词说完了。

念 /ˈkɜːrsɪv/，两音节。全小写书写，不首字母大写。

## 标志怎么读

一段刚写到一半的文字，三行：

- **第一行**有一个灰色的方块——那是 markdown 标记。因为**光标正停在这一行**，标记才显形。
- **第二、三行**没有标记。光标不在，它们已经是排好版的成品。
- **蓝色那根**就是光标，停在第一行的末尾，正在写。

标记与成品共用同一段文字，是光标决定你此刻看见哪一面——这既是"所见即所得"，
也正是 cursive 的核心机制：*光标移进哪一行，哪一行才回显源码。*

形体上全部是圆头胶囊块，有厚度、有落影、有受光的顶面；蓝光标是整个标志里唯一的彩色、
唯一发光的东西——名字里的那个 cursor，就是它。底是一块温润的纸色瓷砖。

标志里没有"草书"的笔迹，这是故意的：字标和图标都是规整的几何单线，*cursive* 的意思
由名字本身承担，不必让图形再演一遍——真让图形去写草书，只会和圆头胶囊块打架。

## 文件

| 文件 | 用途 |
|---|---|
| `app-icon.svg` | macOS 应用图标 1024，**主版本**（纸色底） |
| `app-icon-dark.svg` | 应用图标深色变体 |
| `logo-mark.svg` | 标志，无瓷砖底，浅背景用 |
| `logo-mark-dark.svg` | 标志，无瓷砖底，深背景用 |
| `logo-mark-mono.svg` | 单色，跟随 `currentColor`（印刷、刻印） |
| `logo-lockup.svg` / `-dark` | 图标 + 字标横排组合 |
| `wordmark.svg` / `-dark` | 字标单独用 |
| `favicon.svg` | 16–32px 专用简化版（两行 + 光标） |

字标是纯路径的圆头几何单线体，x 高 56、笔画 13、圆头收笔，与图标的胶囊块同一套语言；不依赖任何字体文件。

## 颜色

| 角色 | 值 |
|---|---|
| 瓷砖 · 纸 | `#fbf9f5` → `#efe9de` → `#d9d1c2` |
| 瓷砖 · 墨（深色变体） | `#434049` → `#26242b` → `#141317` |
| 墨块 | `#4c463e` → `#201e1b` |
| 标记块 | `#bdb5a7` → `#948b7d` |
| 光标 | `#a8d6ff` → `#3f93f2` → `#0f51ae` |
| 光标辉光 | `#3d90f0` @ 34% |

光标蓝与 app 的 `--accent`（`#0969da` / `#6ba6e8`）同族：标志上发光的这一根，
在产品里就是选中、链接和光标的颜色。

## 用法

- **留白**：四周留出不少于一个行块高度（图标边长的 7%）的空白。
- **最小尺寸**：图标 32px，组合标志 140px（字标比 typmd 时代长，要多给一点）。再小请用 `favicon.svg`。
- **别做**：别拉伸、别改三行的长短关系、别把光标挪到别的行（标记和光标必须同行，
  否则语义就反了）、别给图标再加外阴影或描边。

## 重新生成应用图标

矢量源是 `app-icon.svg`，`scripts/icon.html` 是与它同步的 1024 导出页。

```
# 浏览器打开 scripts/icon.html，透明背景截图 1024×1024 → build/icon.png
npm run icon      # build/icon.png → build/icon.icns
```
